# Upstream provenance

- Original solver: https://github.com/sontanon/SPHBOSON
- Upstream branch: `master`
- Upstream base commit: `0f582b3 Correct .gitignore.`
- Upstream author shown by the solver: Santiago Ontanon Sanchez, ICN UNAM

This derivative keeps the upstream Git history and adds:

- free, quartic, sextic, axion, solitonic, and KKLS potential selection;
- consistent potential terms in the nonlinear residual and analytic Jacobian;
- potential-aware solution directory names and run metadata;
- static metric export compatible with the ROTBOSON ISCO scanner;
- focused potential/export tests and PolyU HPC templates.

must be obtained from the upstream author as appropriate.
